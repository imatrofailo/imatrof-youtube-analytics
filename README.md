# imatrof YouTube Analytics

Публічний frontend і data/storytelling layer для аналітики YouTube-коментарів каналу `@imatrof`.

Цей файл є коротким описом для людей.

Повний агентний контекст, canonical frontend surface, operational pipeline, deployment flow і робочі правила для майбутніх агентів описані в `agents.md`.

Live production surface цього репозиторію зводиться до root-level `index.html`, `styles.css`, `app.js` і `site-data.json`.
